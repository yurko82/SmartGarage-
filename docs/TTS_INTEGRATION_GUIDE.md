# Інструкція з налаштування та тестування українського TTS у SmartGarage

> **Версія:** 1.0  
> **Дата:** 03 листопада 2026 року  
> **Базовий провайдер:** Microsoft Edge Neural TTS (`uk-UA-PolinaNeural`, безкоштовно)  
> **Резервний контур:** Web Speech API у браузері або Edge TTS на сервері  

---

## 1. Архітектура та принципи підсистеми TTS

Модуль голосового синтезу розташовано в директорії `server/tts/`. Він складається з таких компонентів:

- **`normalizer.py`**: Нормалізація українського тексту (числа, відсотки, температури, збереження апострофів у словах на кшталт `п'ять`, `м'ята`, видалення емодзі та розмітки).
- **`cache.py`**: Локальний TTL-кеш аудіофайлів для уникнення повторного синтезу частих фраз.
- **`base.py`**: Базові абстрактні інтерфейси `TTSProvider`, `TTSResult`, `TTSVoiceInfo` та типізовані винятки.
- **`edge_provider.py`**: Адаптер безкоштовного синтезу Microsoft Edge (голоси Поліна та Остап).
- **`elevenlabs_provider.py`**: Адаптер для ElevenLabs Flash v2.5.
- **`heygen_provider.py`**: Адаптер для HeyGen Voice Turbo REST.
- **`manager.py`**: Оркестратор синтезу з автоматичним каскадним fallback на безкоштовний Edge TTS.

---

## 2. Підтримувані провайдери та налаштування

| Провайдер | Ідентифікатор | Формат | Ліцензія / Вартість | Змінна середовища | Статус |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **Microsoft Edge Neural** | `edge` | `audio/mpeg` (MP3) | Повністю безкоштовно | Не потрібна | **Baseline за замовчуванням** |
| **ElevenLabs Flash v2.5** | `elevenlabs` | `audio/mpeg` (MP3) | ~$0.04 за 1k символів | `ELEVENLABS_API_KEY` | Преміум надшвидкий кандидат |
| **HeyGen Voice Turbo REST** | `heygen` | `audio/wav` (WAV) | Turbo Free (до 30.11.2026) | `HEYGEN_API_KEY` | Хмарний кандидат |

### Важливі застереження щодо HeyGen:
1. **Жодних вигаданих Voice ID:** Система не містить жорстко закодованих фіктивних ідентифікаторів голосів HeyGen. Перелік доступних українських публічних голосів отримується виключно динамічно через API `GET /v3/voices?language=Ukrainian&type=public`.
2. **Спільна потужність:** Безкоштовний тариф Turbo Free має обмежену пропускну здатність і не гарантує фіксованого SLA, тому система завжди має резервний контур.
3. **Безпека секретів:** Ключ `HEYGEN_API_KEY` зберігається виключно на сервері в `.env`. Frontend отримує лише списки імен та статус конфігурації.

## 3. Налаштування через вебпанель

У вебпанелі керування (`/dashboard`) доступне інтерактивне вікно налаштування TTS:
1. **Перемикання та статус:** У блоці «Голосовий помічник AI» кнопка **`⚙️ TTS: Edge (Поліна)`** відкриває панель вибору.
2. **Вибір провайдера та голосу:** Випадаючі списки відображають лише дійсні та налаштовані голоси. Якщо сторонній провайдер не має API-ключа, відображається мітка `(потрібен API-ключ на сервері)`.
3. **Прослуховування (Прев'ю):** Кнопка `▶ Прослухати` викликає ендпоінт `POST /api/voice/preview` без зміни активної конфігурації.
4. **Збереження:** Кнопка `Зберегти` викликає `POST /api/voice/config` (захищено авторизацією).
5. **Відображення Fallback:** У разі збою вибраного сервісу в заголовку відповіді надсилається `X-TTS-Fallback: true`, а інтерфейс чітко показує попередження: `⚠️ Резервний синтез: використано Edge TTS` або `⚠️ Резервний синтез: браузерний голос`.

## 4. Тестування з моками (Unit Tests)

Усі тести підсистеми TTS виконуються **повністю без зовнішніх мережевих викликів та без витрачання коштів** завдяки мокам `unittest.mock`.

### Запуск тестів:
```bash
python3 -m pytest tests/test_tts.py -v
```

### Що перевіряють тести (`tests/test_tts.py`):
1. **Нормалізатор:** Відмінювання чисел, числівників, температур, вологості, апострофів та скорочення тексту.
2. **Кеш аудіо:** Збереження, читання, витіснення застарілих файлів (TTL) та обмеження максимального розміру.
3. **HeyGen Provider:** Обробка відсутності ключа (`TTSAuthError`), симуляція успішного WAV-синтезу через мок, обробка помилок 429 з бекофом, 5xx та пошкоджених відповідей без аудіо-посилання.
4. **ElevenLabs Provider:** Симуляція MP3-синтезу, обробка 401/403 та 429 лімітів.
5. **Manager Fallback:** Автоматичний перехід на безкоштовний Edge TTS у разі недоступності основного провайдера.
6. **API Endpoints:** Ендпоінти `/api/voice/tts`, `/api/voice/providers`, `/api/voice/config`, `/api/voice/preview` з перевіркою заголовків безпеки, відсутності витоку секретів та прапорця `fallback_to_browser`.

## 5. Скрипт порівняння провайдерів

Для отримання детального звіту вартості та генерації контрольних аудіофайлів використовуйте скрипт:
```bash
# Перегляд аналітичного звіту та цін:
python3 scripts/evaluate_tts_providers.py

# Генерація тестових MP3-файлів українською мовою:
python3 scripts/evaluate_tts_providers.py --generate
```
Аудіофайли зберігаються у директорії `output/tts_comparison/`.
