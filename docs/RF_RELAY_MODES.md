# Режими роботи та процедура сполучення 433 МГц реле (RF_RELAY_MODES.md)

Цей документ описує параметри 4-канального силового блоку реле 12V 433.92 МГц, підтримувані апаратні режими роботи контактів та покрокову процедуру прив'язки (навчання) каналів до сигналів ESP32 (CC1101).

---

## 1. Апаратні параметри блоку реле

* **Напруга живлення:** 12 В постійного струму (DC 12V).
* **Кількість каналів:** 4 незалежних реле (сухі контакти NO / COM / NC).
* **Радіомодуль:** Супергетеродинний приймач 433.92 МГц ASK/OOK.
* **Підтримувані протоколи:** EV1527, PT2262, PT2260, SC5226.
* **Органи керування на платі:** 
  - 1 фізична кнопка навчання («Learn» / «Кнопка програмування»).
  - Світлодіодний індикатор стану (LED).

---

## 2. Режими роботи реле (Залежно від кількості натискань кнопки Learn)

Типові 4-канальні модулі реле 12V (наприклад, KR1204 / AK-RK04S) підтримують вибір режиму роботи за кількістю натискань кнопки Learn:

1. **Режим 1: Моментальний / Імпульсний (Momentary / Inching)**
   - *Активація:* 1 натискання кнопки Learn.
   - *Поведінка:* Реле замкнене лише під час утримання сигналу в ефірі; відпускання кнопки розмикає контакт.

2. **Режим 2: Перемикання (Toggle / Self-locking)** — *Рекомендований для вимикачів без окремого OFF*
   - *Активація:* 2 натискання кнопки Learn.
   - *Поведінка:* Одне натискання вмикає канал, наступне надсилання того самого коду вимикає його.
   - *Особливість:* `code_off = code_on`. Сервер відстежує стан логічно, оскільки реле не має зворотного зв'язку.

3. **Режим 3: Фіксація / Блокування (Latching / Interlocking)** — *Для взаємовиключних каналів*
   - *Активація:* 3 натискання кнопки Learn.
   - *Поведінка:* Вмикання одного каналу автоматично вимикає всі інші.

4. **Режим 4: Роздільні команди ON / OFF (2 канали Toggle + 2 канали Momentary або роздільні ON/OFF)**
   - *Активація:* 4 або більше натискань (відповідно до документації конкретної плати).

5. **Очищення пам'яті (Скидання всіх вивчених кодів):**
   - Натиснути кнопку Learn 8 разів (або утримувати 8-10 секунд). Світлодіод блимне кілька разів і згасне: пам'ять очищено.

---

## 3. Таблиця розподілу радіокодів ESP32 (`config/rf_mappings.json`)

Кожен канал має унікальну комбінацію кодів без дублювання:

| Канал / Зона | Призначення | Код ON (DEC / HEX) | Код OFF (DEC / HEX) | Протокол / Біти / Затримка |
|---|---|---|---|---|
| **basement_light** | Підвал: Світло | `15835393` (`0xF1A101`) | `15835394` (`0xF1A102`) | Proto 1, 24-bit, 320 us |
| **basement_fan** | Підвал: Вентиляція | `15835395` (`0xF1A103`) | `15835396` (`0xF1A104`) | Proto 1, 24-bit, 320 us |
| **floor2_kitchen** | 2-й поверх: Кухня | `15835397` (`0xF1A105`) | `15835398` (`0xF1A106`) | Proto 1, 24-bit, 320 us |
| **floor2_living_room** | 2-й поверх: Вітальня | `15835399` (`0xF1A107`) | `15835400` (`0xF1A108`) | Proto 1, 24-bit, 320 us |

> [!NOTE]
> Якщо реле налаштовано в режимі **Toggle (2 натискання)**, для відповідного каналу в конфігурації виставляється `code_off = code_on`.

---

## 4. Покрокова інструкція прив'язки (навчання)

Для кожного каналу виконується наступний цикл:
1. Власник переводить плату реле в режим навчання потрібного каналу (натискає кнопку Learn необхідну кількість разів — світлодіод на платі загоряється постійним світлом).
2. Запускається постійна трансляція коду (наприклад, `CMD:RF_PAIR:15835393:30` або через ендпоінт `/api/rf/pair`).
3. Світлодіод на реле блимає 3-4 рази і гасне: код успішно збережено в пам'ять реле.
4. Контрольна перевірка: надсилання `CMD:RF_SEND:15835393` перемикає реле із характерним клацанням.
