# Довідка для власника щодо архітектурних рішень (Фаза M4)

## 1. Питання використання Open Interpreter
### Поточний стан (Виконано):
* Бібліотеку `open-interpreter` видалено зі списку обов'язкових залежностей `requirements-ai.txt`.
* Модулі `server/ai/chat.py` та `server/ai/manager.py` захищено конструкціями `try/except ImportError` з виведенням безпечних повідомлень.
* У продакшн-середовищі збережено режим за замовчуванням `ENABLE_OPEN_INTERPRETER=false` (безпечний режим, захист від довільного виконання коду).
* Основна робота AI виконується через прямий клієнт `OpenRouterClient` (Gemini, Claude, GPT через OpenRouter) та локальну модель `Ollama`.

### Що змінилося:
1. **Зменшення обсягу віртуального оточення:**
   * Звільнення дискового простору та спрощення інсталяції в новому venv.
   * Усунення важких залежностей (`litellm`, `selenium` тощо).
2. **Безпека:**
   * Повністю виключено ризик ненавмисного або неконтрольованого виконання стороннього коду безпосередньо на хості.

## 2. Питання уніфікації веб-інтерфейсу (Front-end)
### Поточний стан (Виконано):
* Створено єдиний клієнтський API-модуль `server/static/js/api.js` (об'єкт `window.GarageAPI` / `window.SG_API`).
* Модуль підключено до обох сторінок: `index.html` та `dashboard.html`.

### Що забезпечує `api.js`:
1. **Уніфікований транспорт запитів:**
   * Автоматичне прикріплення `X-CSRF-Token`, підтримка `JSON` serialization, централізована обробка мережевих та HTTP-помилок українською мовою.
2. **Автентифікація (`GarageAPI.auth`):**
   * Єдиний метод валідації PIN-коду (`verifyPin`), збереження сесії в `sessionStorage` та виходу (`logout`).
3. **Керування пристроями (`GarageAPI.devices`):**
   * Керування основним та зональним світлом, воротами, проектором та зчитування стану.
4. **Аудіо та Мультимедіа (`GarageAPI.speaker`):**
   * Керування гучністю (JX-BT, Clip 5), запуск інтернет-радіо, пауза/відтворення, підключення Bluetooth.
5. **Телеметрія та Присутність (`GarageAPI.telemetry`):**
   * Отримання останніх вимірювань, історії для графіків, стану BLE-присутності та запуск сканування.

### Результат:
* Обидва шаблони (`index.html` для швидкого мобільного керування та `dashboard.html` як повноцінний кіоск) збережено, але позбавлено дублювання низькорівневої логіки мережевих викликів.
