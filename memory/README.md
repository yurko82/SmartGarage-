# Memory Directory (Пам'ять SmartGarage)

Цей каталог містить персистентну базу знань та стан апаратної конфігурації розумного гаража.

## `memory.json`

Файл [`memory.json`](file:///home/yurko/AI/SmartGarage/memory/memory.json) відстежується в Git навмисно за вимогою користувача та правилами проєкту, оскільки:
1. **Синхронізація між терміналами та пристроями:** Користувач працює з сервером гаража з різних ноутбуків і терміналів. Git є єдиним джерелом правди для збереження актуального стану обладнання та сесій налагодження.
2. **База знань для ШІ-агента (Antigravity):** Файл містить інвентар виключно **фізично підключеного** та верифікованого обладнання (ESP32-S3, датчики клімату Mijia BLE, аудіо-колонки, проєктор) відповідно до головної політики:
   > *"Only report and track physically installed hardware. Never fabricate or assume presence of unverified GPIO sensors until physically connected."*
3. **Фіксація кроків траблшутингу:** У блоці `audio_troubleshooting_state` фіксуються останні висновки діагностики та план дій для відновлення робіт без втрати контексту між перезапусками сесій.

> **Примітка щодо безпеки та гігієни:**
> Файл не містить чутливих секретів (паролів, API-ключів, токенів). Усі конфіденційні змінні оточення зберігаються у `.env` (який додано до `.gitignore`).
